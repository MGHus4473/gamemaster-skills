# 规程制定

用于羽毛球、乒乓球、网球、匹克球的规程起草、修订和审查。目标是让参赛者知道能否参加、怎样报名、怎样比赛、怎样确定成绩及处理变更。历史规程仅提供写作样本，不能作为技术规则的权威依据。

## 执行顺序

报名结束后并组、取消、让分或预留规则发生变化时，读取 [报名转竞赛](registration-transition.md)。补充通知与最终项目映射、让分对照、奖励及确认/退出窗口共用同一确认版本；不将历史赛事的让分或退款政策自动套入本场。

1. 阅读用户已有资料，区分报名预通知、规程、补充通知、秩序册；记录文件版本、日期及条款出处。图片和扫描页须阅读或 OCR，不把提取不到文字当成空白。
2. 整理已确认、待确认、不适用三类信息；不同版本有冲突时给出差异，不能仅凭文件名“新版”或修改时间认定效力。
3. 使用下方首轮问法收集缺项；已有信息不再问。用户不确定赛制时，依据预计人数、场地时段和办赛目标提出可选方案，建议与已定要求分开。
4. 根据条件补问，按 [内容模板与校验](regulation-content.md) 选择规程或补充通知模板。年龄和组合资格按 [组别设计](age-group-design.md) 明确；按 [专业表述](regulation-language.md) 统一术语和层次。用户只需草案时保留“【待确认：具体事项】”并列缺项，不能称为正式稿。
5. 将已确认事实填入内容参数，运行内容检查与编译；检查本文件末尾的矛盾及程序未覆盖的自由文本，再按 [输出说明](regulation-output.md) 生成格式。用户要求修改时保留未变事实，检查连带影响并重新生成同版文件。

## 首轮询问

先用一小段概括已知信息，只列尚缺的项目。无资料时可用以下五组问题，允许用户回答“待定，请建议”，不要求填写内部技术字段：

1. **赛事基本情况**：叫什么名字，举办什么项目，由谁组织，何时、在哪个场馆举办？
2. **参赛范围**：面向哪些人，设哪些项目和年龄／水平组，预计各有多少人、对或队，是否允许兼项？
3. **报名与费用**：怎样报名、何时截止、联系谁，是否收费，收费单位及退费办法是什么？
4. **比赛与奖励**：已有赛制、计分、晋级、录取名次和奖品要求吗？如需建议，请提供场地数及每天可用时间。
5. **交付方式**：需要 Word（.docx）、PDF、Markdown（.md）、纯文本，还是 LaTeX 编译的 PDF＋.tex 源文件？可多选；是讨论草案还是准备发布的规程，有没有指定公文风格或篇幅？

如果用户要求先给框架，直接给带待定标记的草案并附关键缺项。若未指定格式，询问时可推荐 Word＋PDF；等待期间先整理内容，不能声称用户已选定。用户明确让自行选择时采用 Word＋PDF。输出目录优先用用户指定赛事目录，不把赛事成果写入 skill 本体。

## A. 基本信息：正式规程需要明确

这里的“必需”是赛事执行与信息完整性要求，不表示所有赛事均有相同法定格式。相关办法可以明确引用可获取的适用规则，无须抄写整本规则。尚未开放报名的预通知可以保留待定项。

| 信息 | 至少明确到什么程度 | 常见遗漏 |
|---|---|---|
| 赛事身份与组织者 | 名称、运动项目、届次或年份、主办或实际负责组织者 | 不强制虚构承办、指导、协办单位 |
| 时间与地点 | 起止日期、比赛时段或后续日程的公布安排、场馆及可定位地址 | 报到与比赛时间分开；星期与日期相符 |
| 项目与组别 | 单打／双打／团体、性别组成、年龄或水平范围 | 项目与团体子场不能混为一谈 |
| 资格与限制 | 参赛对象、资格核验办法、跨组与兼项上限 | “可兼一项”改为“每人最多报几项” |
| 报名与联系 | 报名渠道、起止或截止时点、需交材料、确认成功条件、有效联系渠道 | 二维码未提供时不编造；内部邀请赛写明邀请确认方式 |
| 费用状态 | 免费、单位承担或收费；收费时明确金额及按人／对／队计价 | 双打两人不等于收两份每对费用 |
| 赛制与晋级 | 各组别／阶段采用什么赛制、小组出线名额、后续席位来源 | 人数未定时写人数触发方案与公布时间，不能全部留给临场决定 |
| 计分与排名 | 局／盘胜制、每局或盘计分、平分处理、循环排序及同分处理依据 | 区分团体胜场、单项局数、网球盘／局／分 |
| 抽签与赛程 | 抽签办法、种子和回避政策（有则写）、结果及日程公布渠道 | 已知日期写日期，未定则写明确公布安排 |
| 名次与奖励 | 决出哪些名次、是否并列、是否发奖；无奖励也可明确说明 | 独立季军赛与并列第三只能择其适用者 |
| 检录与异常处理 | 检录方式、迟到起算点与后果、弃权退赛及结果处理依据 | 提前到场建议与判弃权时限不能混写 |
| 异议与变更 | 资格／竞赛异议向谁、何时、以何方式提出；变更如何通知 | 解释条款不能替代申诉程序或容许无限制变更 |
| 安全与发布信息 | 实际安全联系及处置安排、发布主体、发布日期或版本 | 不捏造医疗团队、保险承保或已签署的承诺 |

## B. 条件触发后必须补齐的信息

补充信息不等于可随意删除；先判断是否适用，再追问相关条件。

| 触发条件 | 应补问并写清的内容 |
|---|---|
| 年龄分组／青少年 | 出生日期区间及端点，或周岁计算基准日；跨龄规则；监护人同意与紧急联系安排。不能仅凭 U 名称推算年份。 |
| 双打／亲子 | 两名成员资格、跨单位与跨组配对、组合年龄按谁计算、搭档变更截止；亲子关系及成人资格。 |
| 团体 | 每队人数、男女构成、替补、子场顺序、同一次对抗兼项限制、阵容提交／调整、先达胜场停止还是打满全部子场；每个子场另定局制。 |
| 分组循环 | 胜负积分、两人／多人同分比较范围与顺序、退出后成绩保留方式、跨组比较办法；引用规则时指明适用章节。 |
| 分阶段／附加赛 | 各阶段计分差异、晋级对位、季军赛或全名次赛、是否重新抽签；阶段人数须衔接。 |
| 种子／单位回避 | 种子依据、数量、回避范围和无法满足时的处理办法，不默认保证全部回避。 |
| 收费／保证金 | 缴费时间与确认，个人退赛、资格不符、并组、延期取消各情形的退费办法；保证金用途、扣款依据、退还时限；奖品及费用按人／对／队区分。 |
| 不足人数并组／取消 | 最低人数及计量单位、合并顺序、跨年龄性别规则、调整计分与奖励、公告时间、接受或退出的处理窗口。 |
| 让分或特殊玩法 | 谁让谁、每局起始比分、是否叠加、封顶及换边如何计算、适用组别；列明确对照，不能沿用历史赛事数值。 |
| 专业等级／单位资格 | 排除或准入的等级、现役／退役状态、工作关系、资格材料与异议期限；“非专业”等模糊词需解释。 |
| 保险／健康材料 | 谁购买、是否为报名条件、有效期间和核验方式；按实际安排写健康声明及现场救助，不能用免责文字取代安全安排。 |
| 户外或多场馆 | 天气暂停、延期／取消及通知办法，转场时间；网球场地类型、用球与换球安排。 |
| 服装／器材限制 | 比赛用球及提供方、球拍／胶皮或服装要求，仅写实际适用限制；不复制其它项目规定。 |
| 官方积分／反兴奋剂／纪律制度 | 仅在赛事等级与适用制度要求或主办方明确决定时引入，核验规范名称及版本；不虚构检查、处罚权限或上报机制。 |
| 摄影直播／个人信息 | 所需材料的用途、公开范围、肖像使用目的及告知方式；不默认无限期商业授权，不在公开规程附真实证件及报名明细。 |

## C. 可选额外内容

活动宗旨、宣传主题、赞助鸣谢、开闭幕式、领导名单、交通停车、食宿推荐、赠品、服装尺码、教练员奖、文明参赛倡议、签名附件等按需求加入。区分组织手册和参赛规程，内部工作分工及全体裁判名单通常放秩序册。

选定赠品、食宿服务或其他权益后，领取条件、数量、有效期等成为需兑现的具体信息；不能因为原属可选内容就写得含糊。

## 精简官话与套话

按 [专业表述](regulation-language.md) 判断是否可删减：宣传口号按需求压缩，资格、程序、费用、奖励和执行责任保持明确；不把责任条款当普通套话删改。该参考同时维护句式示例和不得擅自补定的规则，避免在本文件重复。

## 运动项目的技术信息分支

此表是采集清单，不是一套固定规则。赛事日期确定后，核验指定协会文件及自定办法。

- 羽毛球：局胜制、目标分、领先分、封顶、间歇与换边、让分适用范围；团体对抗与单项场次分层描述。
- 乒乓球：局胜制、目标分、平分后领先要求、发接球轮换、决胜局换边、暂停及团体出场制式；不能照搬羽毛球的封顶或弃权统计办法。
- 网球：盘胜制、每盘局制、有占先／无占先、何时抢七及目标分、决胜盘或抢十替代、短盘／青少年用球和场地、局间与场间休息；不能把抢十当成普通一局统计。
- 匹克球：侧出得分或每球得分、局胜制、目标分、领先分/封顶、发球与换边、单打或双打；不同组织和赛事使用版本分别记录。与另三项的版本选择和解读方法见 [运动规则](sport-rules.md)。

优先查本赛事指定协会的官方文件。国际规则核验入口：[BWF](https://corporate.bwfbadminton.com/statutes/)、[ITTF](https://www.ittf.com/handbook/)、[ITF](https://www.itftennis.com/en/about-us/governance/rules-and-regulations/)。引用时记录文件名称、版本、生效日、条款或页码和链接；打不开或无法确认时明确待核验，不编造“最新规则”。

## 交付前重点检查

- 名称、年份、日期与星期、场馆在正文和附件一致；删除上一届、上一场赛事遗留信息。
- 声明互斥且连续覆盖的年龄、人数、奖项区间不重叠不漏档；允许交叉的公开组等另写兼报规则。检查边界值及“以下／以上／前／后”是否含端点。
- 总规模与各项目名额一致，人数／对数／队数明确；不同时写总量受限与无条件不限人数。
- 计分、封顶、加分与换边自洽；团体几场几胜和单项几局几胜分别写清。
- 晋级名额、淘汰人数、录取名次及季军赛相符；同分排序、弃权处理有可执行依据。
- 检录起算点明确，比赛延误和紧跟前场不应导致选手被错误判迟到。
- 费用、退款、奖品及并组调整相互一致，不虚构联系人、报名链接、金额或时限。
- 补充通知只覆盖明确修改部分；历史材料存在冲突先列差异，不拼成混合版本。
- 涉及具体技术判罚先核验官方条款；少写不必要的规则教学，避免把其它运动项目规则写进来。
- 正式稿不能残留“XXX”、草案占位或未决核心项。草案把待确认清单与参赛者正文分开，多格式输出使用同一份内容。
