# 羽毛球规则知识库

供标准羽毛球规则问答及赛事参数核对使用。世界羽毛球联合会简称BWF，中国羽毛球协会简称中国羽协/CBA；此处CBA不是篮球联赛。公开包保存原创中文解读、条款定位和来源指纹，规则原件放赛事工作区或知识库缓存，不随skill发布整本手册。

## 检索与回答

知识数据在 [badminton/knowledge.json](badminton/knowledge.json)。不必一次读完整数据，可在skill目录运行：

```bash
python scripts/badminton_rules.py status
python scripts/badminton_rules.py search "发球旋转" --on 2026-10-07 --authority BWF
python scripts/badminton_rules.py search "计分" --on 2027-01-04 --include-inactive
python scripts/badminton_rules.py search "2025规则书" --authority CBA
```

脚本仅用标准库、无联网操作；默认日期取运行当天，复盘或筹办赛事用真实比赛日期。结果是可引用的知识卡，不是自动裁判。每条显示适用状态、版本、条款、原件页码、来源链接与核验日。未命中、仅有历史摘要或版本公告时须补查正文，不能用搜索相似度代替证据。跨协会比较用 `--authority all`，并分别陈述；不把BWF条款号写成中国羽协条款号。

一般问题先依据适用规则直接回答，再标明条件；具体争议只补问会改变结论的事实（比赛日期/采用版本、单或双打、球是否已死、初始击球点、谁先触网等）。正文默认简明中文，正式裁判意见可按单位文件风格展开。回答至少包含：

- **结论与条件**：例如“按BWF标准规则，单纯擦网后落入正确发球区仍可合法，不自动重发；停在网顶或过网后挂网要另判。”
- **依据**：文件名、版本/生效日期、条款号及可点击原文链接，PDF可加 `#page=N`；本库中文解释不是协会授权译文。
- **边界**：必要时注明赛事另行采用的变式、尚缺事实或未核实正文。不要用一段笼统免责文字代替明确结论。

普通双打知识卡不覆盖全部残疾人羽毛球、AirBadminton、特殊团体赛、试行规则、即时回放、服装广告、兴奋剂及医务细则；涉及这些问题另查对应专项文件。旧规则图片没有写“禁止加转”，不能据此推出当前允许旋转发球。

原始网址与SHA-256在知识数据中。BWF主站规则目录本次受访问限制，但已取得官方文档站的Laws V5.0(2)与GCR；镜像资料明确区分发布机构与托管协会。不得笼统声称“两个协会全部最新规则已收录”。

本地书稿的 `url` 为null，以 `cache_file`、哈希、书页码 `printed_pages` 和PDF页码 `pages` 定位，不把馆藏链接当成条文原文。`reviewed_edition_evidence=true` 表示该版本引用已对照原页，`rule_evidence=true` 表示符合已知生效时间线；二者不同。`needs_primary_source=false` 也不代表当前适用，仍须检查 `needs_applicability_check`。OCR命中只用于找页，不是已核验知识卡。

## 与赛事制作连接

先锁定赛事实际采用的版本，再将确认参数传给规程、编排和成绩脚本。BWF标准21分与已公布15分制采用不同的目标分、封顶、局内间歇触发分和决胜局换边分；不能只把21改成15。地方31分、一局制、让分、年龄资格和开赛人数单独记录，不称为协会默认。

两场比赛的休息从上一场**实际结束**到下一场开始计算，跨项按同一人核对；局内60秒/局间120秒不能替代场间休息。GCR V8.0场间休息在**11.4**，ITTO V8.0(2)内仍引用旧GCR 11.3。是否适用GCR、青少年或其他专项规则先确认；不把国际成人赛事的60分钟自动写入所有地方赛，也不把本地15分钟策略说成符合BWF通则。

循环同分须区分全组净胜局/分与同分者互赛、单项与团体。知识库说明规则不等于成绩引擎已经实现全部协会算法；映射到 [成绩契约](results.md) 后仍须逐条核对，尤其是“仅剩两方比较相互胜负”和未完成全组比赛的删除规则。不能为匹配现有配置改写协会条文。

## 更新与验收

需要“最新”答案、日期晚于核验日、来源冲突或遇未覆盖专项时，从[BWF目录](https://corporate.bwfbadminton.com/statutes/)及[中国羽协官网](https://www.cba.org.cn/)找对应原文。站内搜索、新闻和第三方页面只用于定位；采纳事实须回到协会正文或明确标注的官方版本公告。目录标题“最新”、文件上传年月、转载日期都不等于生效日期。

下载原件到skill外的缓存。核对封面、版本、生效日和相关完整条款，图表及扫描页做视觉复核；与前版比较后再更新 `sources`、`cards` 及核验日期。只查到新版封面不能把旧版全部知识卡自动升级。未来版单列；每个中文结论保留其原文引用，若未核清则保留缺口。

中国羽协正文优先采用2025版；无法取得时，可接入其他年份的完整规则书作为有年份标识的基础资料。接入时：

1. 核对书名、审定/编译机构、版权页、版次、ISBN、目录及正文末页；分别记录印刷页码和PDF页码。按该版目录检查全部章节、附录、图表是否齐全，不能把“比赛规则”一章、简易版或出版公告标作整本规则书。
2. 原书及OCR文本保存在用户资料区，公开skill只补入经原页核对的原创摘要、条款定位和来源指纹。OCR中的否定词、比分、时间、条款编号、图示及跨页内容须对照原页；哈希变化触发重新审阅，不自动认证新版本。
3. 旧版保持原年份，不因入库日期较新而升级为现行版。对现行问答逐条核对后续中国羽协修订及赛事实际采用版本；只有BWF依据时明确回答“按BWF”，不能据此声称已核实中国羽协同款条文。
4. 目录、馆藏或售书记录只证明版本存在，不证明已取得正文。未取得完整原件或有缺页时继续保留证据缺口，不能拼接不同年份的节选并称为“完整正文”。

```bash
python scripts/badminton_rules.py verify-cache /path/to/rule-cache
python -m unittest discover -s tests -p 'test_badminton_rules.py'
```

第二条在源仓库根目录执行，测试文件不要求随已安装skill分发。验收覆盖生效日期边界、协会隔离、未来/历史资料标识、漏证据拒绝、发球及判罚易错点；脚本通过仅证明检索与版本选择行为，不等于已自动裁定所有现场争议。
