已登记扫描件334个PDF页，书末页码332，无原生文本层。文件SHA-256见 `knowledge.json` 的 `cba-book-2023`，缓存名 `cba-book-2023.pdf`。原件和OCR放skill外，不随公开包发布。

- 书页码287、303缺失，英文技术官员指南存在正文断档。
- 书页码160、196、220未出现，位于章节交界，是否原为空白页尚未确认。
- 已检查全部页脚的页码序列、章节交界及缺页两侧；没有逐字校对全书。已核验知识卡仅引用登记过的原图页面，图表和未覆盖专项按问题另核。

因此将来源登记为 `partial_scan_reviewed`，不能标成完整规则书或完整校对本。缺页不能用别的版本无标记补齐。

## 离线OCR与全文定位

构建依赖预先安装的 `pymupdf`、`rapidocr_onnxruntime`（本次核验1.4.4及随包模型）。脚本不调用云端，不自动安装依赖；查询索引仅需Python标准库。

```bash
python scripts/rulebook_scan.py build /path/book.pdf /path/new-index --workers 2
python scripts/rulebook_scan.py build /path/book.pdf /path/new-index --workers 2 --resume
python scripts/rulebook_scan.py search /path/new-index "场间休息"
```

输出文件哈希、逐PDF页OCR/坐标/置信度及 `全文-OCR待校对.md`。中断后仅可对同一扫描与同一OCR版本续做；`ocr_complete` 仅表示提供文件的全部PDF页完成识别，不表示原书无缺页。表格阅读顺序、边栏、负号、小数点和漏行仍须回原图确认，关键词未命中也不能证明书中没有规定。

## 与现行规则及算法的连接

- 2023版普通计分为三局两胜21分、30分封顶；不得覆盖BWF已登记未来版的15分参数，也不据BWF变更推定中国羽协同日实施。
- 书页8发球条款9.1.5只写先击球托，不能用其未提旋转发球来证明当前允许加转。
- 书页102的单项同分处理使用该组比赛净胜局、净胜分，并有只剩两方时转相互胜负的分支；引擎配置须核对这些分支，引用知识卡不代表已新增算法。
- 书页139含日内/小节比赛负荷、团体与单项顺序及有适用范围的场间休息要求。赛事明确采用这些条款时，登记来源、确认专项例外及后续修订，再转换为编排约束；不因知识库新入库就暗改现有地方赛参数。
