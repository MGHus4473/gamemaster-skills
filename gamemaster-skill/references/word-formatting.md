# Word 规程版式

用户给定模板、单位版式或指定参数优先。先查看模板的纸张、样式、标题层级、表格、页眉页脚和落款要求，再决定沿用模板或使用以下默认值。这是一套专业赛事规程的默认版式，不宣称符合某一法定公文标准。业务条款与表述见 [regulation-language.md](regulation-language.md)，输入结构及其他格式能力见 [regulation-output.md](regulation-output.md)。

默认样式位于 [regulation-word-style.json](../assets/regulation-word-style.json)，`render_regulations.py --format docx` 实际读取并执行，不依赖人工打开 Word 后补样式。

## 默认标准

| 对象 | 执行标准 |
|---|---|
| 纸张 | A4 纵向，210×297mm；上、下、左、右页边距均为25mm，正文宽160mm |
| 中文与西文 | 正文宋体、标题黑体；ASCII/西文另设Times New Roman，不用同一个字体字段替代所有文字 |
| 主标题 | 18pt、黑体加粗、居中、1.3倍行距、段后12pt；不首行缩进，与后段同页 |
| 副标题、版本 | 10.5pt、居中、段后6pt；草案/文件类型另行居中显示 |
| 一级标题 | 14pt加粗；段前12pt、段后6pt、1.3倍行距；真实Heading1与大纲级别0 |
| 二、三级标题 | 12pt加粗；段前/后6pt、1.3倍行距；真实Heading2/3与大纲级别1/2 |
| 正文 | 12pt、两端对齐、1.5倍行距、段前0、段后6pt；首行缩进2个中文字符，启用孤行控制 |
| 导语 | 同正文但无首行缩进；用于需要顶格的说明，不用于给所有正文绕过缩进 |
| 条目 | 12pt、1.5倍行距；编号作者明确提供，使用真正悬挂缩进和制表位；下一级增加2字符的左侧偏移 |
| 落款单位、日期 | 12pt、右对齐、无首行缩进；单位段前12pt，与日期同页；日期段后6pt |
| 注释 | 10.5pt，无首行缩进；不缩小关键参赛条件来隐藏信息 |
| 附件 | 另页开始，附件标题沿用一级标题与大纲级别；标题明确附件编号和名称 |
| 页眉 | 顶端距12.5mm，9pt居中；默认文件类型，未指定类型时为“竞赛规程”；可明确设为空 |
| 页脚 | 底端距12.5mm，9pt居中，“第 PAGE 页 / 共 NUMPAGES 页”为真实域，不写死页数 |

标题启用与下段同页及段内不分页，避免页末孤立标题。正文允许跨页，依靠孤行控制；不对整篇正文启用“与下段同页”。源文本换行生成独立 Word 段落，不能用换行或空格模拟标题、缩进或落款位置。章节编号如“一、”“（一）”放在标题文字中；条目如“1.”“（1）”由 `clause.label` 提供。两者层级分别配置，不自动替作者改号。

## 表格

- 默认占满正文宽度，未给列宽时均分；给定 `column_widths_mm` 时每列至少10mm、总宽不超过正文区域。表格总宽、网格宽和各单元格宽同时写入，使用固定布局，不能依赖自动适应内容。
- 文字10.5pt、1.2倍行距，无首行缩进、段前后0；单元格四边内边距1.5mm。表头加粗居中、浅灰背景，正文左对齐，边框为0.5pt灰线。
- 首行作为跨页重复表头。默认所有行禁止跨页拆分；长表仍可在行之间分页，不能把整张长表强制放在同一页。
- 单个单元格内容超过一页时，应缩短说明、拆成多条，或按用户需要明确设该表 `allow_row_split:true` 后检查分页；不固定行高裁掉文字。表头始终不拆分。
- 表格可有 `caption`，放在表前并与表格同页。多段单元格用换行分隔，生成真实段落。合并单元格、嵌套表、图片、复合表头、脚注及复杂签章区不在该脚本范围内，应使用对应模板/文档工具完成，不能压成丢失结构的普通表。

## 按用户要求覆盖

覆盖优先级：默认资源 → 输入JSON的 `word_style` → `--style-profile` JSON → `--cjk-font`/`--latin-font`。覆盖后重新校验正文宽度及表宽；扩大/缩小用户页面都按最终版式判断。`--cjk-font` 同时覆盖正文与标题中文字体；需要二者不同，使用 `fonts.cjk` 和 `fonts.heading_cjk`。

```json
{
  "page": {"margins_mm":{"top":25,"bottom":25,"left":30,"right":20}},
  "fonts": {"cjk":"宋体","heading_cjk":"黑体","latin":"Arial"},
  "sizes_pt": {"body":12,"title":18},
  "header_text":"示例赛事组委会",
  "table": {"header_fill":"EEEEEE","allow_row_split":false},
  "page_numbers":true
}
```

参数全集以资源JSON为准；未知字段报错。此配置覆盖页面、字体、字号、正文行距/段距/缩进、表格内边距/颜色/行分页、页眉及页码开关，不承诺覆盖任意 Word 样式属性。指定 `.docx` 模板的原有自动编号、节设置、签章或图片版式需要模板编辑流程；本脚本没有“导入模板并无损保留”的功能，不能将模板要求静默替换为默认版式。

字体名称写入 Word 不代表机器装有该字体，脚本不下载或嵌入商业字体。换机时检查字体是否可用；明确替代字体后再检查换行和分页。禁止仅因当前环境缺宋体而假称已按宋体完成视觉验收。

## 验收

结构检查须覆盖纸张/边距、分别声明的中西文字体、样式与标题大纲、真实首行/悬挂缩进、`w:tab`、表格固定宽度和跨页表头、行拆分策略、附件分页、PAGE/NUMPAGES域，以及所有条款/单元格文字完整。检查长表末行和附件末段，不能只抽第一页。

有 Word、WPS 或 LibreOffice 时实际打开/导出PDF，检查每页标题不孤立、列宽不溢出、表头重复、单行不被异常截断、附件不出现多余空白页、落款和页码正常。分页依赖办公软件与字体，XML通过不等于已完成视觉验收。缺少办公渲染器时交付可编辑Word并明确“结构验证通过，实际分页待办公软件复核”；不得拿另一套PDF后端生成的页面冒充Word预览。
