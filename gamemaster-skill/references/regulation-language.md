# 规程的专业表述

起草、润色或审查规程及补充通知时读取。信息是否齐备按 [规程制定](regulations.md) 检查；本文件只约定表达方式。它是本 skill 的写作约定，不是所有赛事必须采用的公文或法律标准。保留用户确认的赛事办法；技术规则按 [运动规则](sport-rules.md) 核验，不能通过“专业润色”擅自补定。

## 术语和计量单位

| 容易混用的概念 | 写法 |
|---|---|
| 报名项目／竞赛项目 | 报名项目记录原申请；竞赛项目指最终实际开赛项目。并组时同时列原项与新项，不能只改名称后丢失原资格、让分或奖励来源。 |
| 人／对／队 | 单打按人、双打按对、团体按队表示参赛名额；运动员总人数另计。费用、开赛门槛和奖励各写明计量单位；“双打每组”改为“每对”，循环“组”另用“小组”。 |
| 项目／组别／小组 | 全文使用同一套命名，例如“U13男子单打”为竞赛项目，“A组”为该项目的循环小组；首次出现简称时给出全称。 |
| 阶段／轮次／场序／小节 | 阶段表示赛制进程；轮次表示对阵关系；场序表示同一时段的比赛批次；小节表示上午、下午等时间段。不要用“第2场”同时表示某选手第二场和全场第2场序。 |
| 场／局／盘 | 单项一场由若干局或盘组成；团体对抗包含若干子场。分别写“团体先胜几场”和“子场几局几胜”；网球盘、局、分分层描述。 |
| 晋级／录取／奖励 | 晋级人数是进入下一阶段的名额；录取名次是需要决出的排名范围；奖励对象及数量另列。决出第3、4名和并列第3名不可混写。 |
| 轮空／预留名额／弃权／退赛 | 轮空是无对手而自动晋级；预留名额是尚未绑定真实参赛者的席位；弃权或退赛是实际报名项的比赛状态。预留者不计为真实运动员，也不因空着就自动记弃权比分。 |

“胜次”“净胜局”“净胜分”“场积分”写明统计对象；同分处理写明比较顺序、比较范围及适用规则。不得把报名表排序、姓名顺序或历史成绩中的并列顺序写成新赛事的排名规则。

## 条款写成可执行的句子

默认接近单位正式公文：规程用“赛事名称＋竞赛规程”，补充通知用“关于赛事相关事项的补充通知”；通知按需列主送对象、制发依据、分条事项、附件、发布单位和日期。一级“一、”、二级“（一）”、三级“1.”层次一致。组织、资格、报名、竞赛、奖励和办理事项分别成章；长资格条件或调整对照用表格。正式风格不等于堆砌宣传词，不凭空写“经研究决定”、上级批准、文号、签章或法定效力。正文模板见 [内容模板](regulation-content.md)。

一个条款处理一件事。涉及办理流程时，按需要写明 **适用对象／触发条件 → 谁执行什么 → 截止时点 → 提交或通知渠道 → 完成标准与异常处理**；不强迫每句话都凑齐全部要素。并列条件用编号，互斥分支用“达到……时／未达到……时”，避免把例外藏在长句末尾。

- “须”表示已确定的参赛要求，“可”表示允许选择，“建议”表示推荐；“原则上”“酌情”“视情况”用于保留调整空间时，同时写触发条件、决定主体及公布安排。不能靠删去这些词将未决事项变成已确认要求。
- 名称用赛事正式名称，动作使用“提交、核验、确认、公布、申请、更正”等具体词。“报到”是办理到场手续，“报道”是新闻报道；“抽签公示”不写成“抽签公式”。
- 检录建议提前多久、迟到从何时起算、由谁判定及其后果分开写；实际延误或调整后的比赛开始时点应按已确认办法处理，不擅自设定弃权分钟数。

以下仅示范已确认参数的写法，例中的日期、金额、人数和分数不能作为新赛事默认值：

| 含糊写法 | 清楚的写法示例 |
|---|---|
| 每人限兼报1项 | 每名运动员最多报名2个项目，其中单打最多1项、双打最多1项。 |
| 双打报名费120元／组 | 双打报名费为每对120元，一对包含两名参赛者。 |
| 年龄在规定范围内 | 出生日期须为2011年1月1日至2012年12月31日，含首尾两日。 |
| 及时申请更换搭档 | 报名联系人须于2026年9月28日18:00前，通过赛事指定报名渠道提交搭档变更申请；新搭档资格核验通过并收到确认后生效。逾期申请按本场已确认办法处理。 |
| 甲类让乙类6分 | 甲类对阵乙类时，每局起始比分为0:6，甲类在前、乙类在后。适用类别及是否叠加按本场已确认对照表写明。 |

## 数字、时间与边界

正文统一使用“2026年10月13日”“09:00—12:00”等清楚形式。跨日区间两端写日期；“截止当天”细化到已确认时分，跨时区赛事补明时区。星期需要时再加，并校对日期；发布日、报名截止日、报到日、比赛日不能互相替代。

年龄资格优先使用已确认的出生日期闭区间，或写“截至某日已满N周岁、未满M周岁”；不能仅凭 U13 等简称推算年份，也不能把“2000年以后”自行解释为是否含2000年。双打年龄条件要说明针对每名成员、年长者、年龄合计或其他已确认方式。

人数、收费、奖励、并组的区间逐一检查端点，特别检查恰好7、8等临界人数。区分“少于8”与“不超过8”；阈值要与各条款使用的人／对／队一致。总名额与各项目名额同时存在时写清分配或截止办法，不并列承诺“总额受限”和“各项无条件不限”。

## 层次、表格与附件

无指定模板时，章节用“一、”，子节用“（一）”，可执行条目用“1.”，确有下级条目再用“（1）”。不为一两句话堆叠多层标题；引用写“第七部分第（一）项”，不只写“见上文”。修订现有规程时保留便于对照的编号，确需重编号则同步改交叉引用。

标题层次与条目层次分别编码。Word 使用真实标题、段落、表格及条目样式，不靠连续空格、手工回车做缩进或分页。渲染字段只维护在 [输出说明](regulation-output.md)：章节对应 `heading`，条目对应 `clause`，编号由明确的 `label` 提供；落款单位和日期分别使用 `issuer`、`date` 段落样式。

组别与资格、阶段计分、名次奖励、并组映射和让分对照适合表格。表头写清单位、甲乙方向及适用范围，一行描述一个可比较对象；“—”表示不适用，0表示数值为零，待定写“【待确认：事项】”，三者不互换。表格较长时重复表头；关键规则不要只放在图片或表下注释中。

附件另列名称并在正文有明确引用；报名表、监护人确认页、补充通知中的赛事名称和版本与正文一致。附录用独立 `appendix` 块，版式与换页由输出规范处理。内部工作人员名单和执行分工按需放秩序册，不挤入参赛规程。

## 补充通知与版本一致

补充通知写明对应的原规程名称、版本或发布日期、适用项目、修改条款、新办法、执行时间，以及需要时的确认／退出窗口和联系渠道。只替换明确列出的部分；发布主体和适用关系需有确认依据，不能以文件名“最终版”、文件修改时间或网页排列顺序自动判断效力。

并组后，正文、项目表、报名到竞赛映射、让分表、奖励表、确认／退出安排和附件使用同一确认版本。让分表说明行列分别代表谁、受让方向、每局起始分与是否叠加；“让6分”不自动解释为赛后加6分。具体参数仍由 [报名转竞赛](registration-transition.md) 流程确认。

## 精简与不得代填的内容

宗旨宣传有需求时保留一句；重复的文明参赛倡议、动员口号和提前到场提醒合并。删除前判断是否会改变资格、办理程序、费用、奖励或执行责任；退费、异议处理和安全安排即使常见，也不是可随意删去的套话。

“未尽事宜另行通知”不能代替核心条款，改为明确补充通知的发布主体、渠道和范围。“最终解释权”不能代替竞赛异议程序。“一切后果自负”“报名即同意全部规定”等不能作为通用免责或确认办法直接套入；具体责任条款应按实际安排及适用依据核验。

不虚构规则版本、计分／同分办法、参赛资格、联系人、时限、罚款、申诉费、保险医疗安排、行政背书或法律效力。遇到如“21分先得者胜、31分封顶”的矛盾，先列冲突并确认，不能默默选一种。正式稿只使用已确认内容；草案将待定项集中列出，不能靠正式语气隐藏未决参数。
